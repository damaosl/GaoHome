# 连点器（Minimal Auto Clicker）

一个极简风格的 Windows 连点器：可自动连点鼠标（左 / 中 / 右键）或连按某个键盘键，
支持自定义触发频率、持续时间与开始 / 结束全局快捷键。

## 功能特性

- 输入类型：鼠标点击 / 键盘按键 / 按键序列（三选一）
- 鼠标：左键 / 右键 / 中键，可选「跟随光标」或「固定坐标」（一键记录坐标）
- 键盘：按下任意键即可录入要连按的键
- 按键序列：多个按键按自定义先后顺序循环触发（可增删、清空）
- 触发方式：连点（点按）/ 长按（按住后松开，时长可自定义）
- 触发频率：0.1 ~ 1000 次 / 秒（连点模式）
- 按住时长：秒（长按模式，0 = 一直按住直到手动结束）
- 持续时间：秒（0 = 不限时，直到手动结束）
- 开始 / 结束快捷键：可自定义，全局生效（窗口失焦也能用）
- 极简暗色 UI，设置自动保存到 config.json

## 环境要求

- Windows
- Python 3.12（含 tkinter）
- pynput

## 安装与运行

1. 安装 Python 3.12（如未安装）：

   ```bat
   winget install Python.Python.3.12
   ```

2. 安装依赖：

   ```bat
   pip install -r requirements.txt
   ```

3. 运行：

   - 双击 `run.bat`
   - 或执行 `python main.py`

## 使用说明

1. 选择「输入类型」：鼠标、键盘 或 按键序列。
2. 选择「触发方式」：
   - 连点：按频率（次 / 秒）反复点按，可持续指定时长。
   - 长按：按住不放，持续指定时长后自动松开（按住时长设为 0 则一直按住，直到点「结束」或按结束快捷键）。
3. 设置频率（次 / 秒）或按住时长（秒）。
4. 键盘模式下，点击「按键」按钮录入要连按 / 长按的键。
5. 按键序列模式下，反复点「添加按键」录入多个键，按录入顺序循环触发；「删除末尾 / 清空」可调整序列（长按模式下则按顺序逐个长按）。
6. 点击「开始快捷键 / 结束快捷键」按钮后按下任意键即可录入（单键）。
7. 点击「开始」或按下开始快捷键即开始；「结束」或结束快捷键停止。

> 提示：请勿把开始 / 结束快捷键设成与「连按 / 长按的键」相同，否则会互相触发。

## 模块结构（按实现顺序）

| 顺序 | 模块          | 职责                                     |
| ---- | ------------- | ---------------------------------------- |
| 1    | `keys.py`     | 键对象 ↔ 字符串、友好显示名的互转        |
| 2    | `config.py`   | 配置的加载 / 保存（config.json）         |
| 3    | `engine.py`   | 后台连点引擎（频率 / 时长 / 停止）       |
| 4    | `hotkey.py`   | 全局快捷键监听 + 按下即录入              |
| 5    | `ui.py`       | 极简暗色界面，串联各模块                 |
| 6    | `main.py`     | 程序入口                                 |
