# 高岛的钢琴课

极简的 Windows 小工具：**从一个视频文件里提取音轨，转成你选的音频格式**。

- 语言：C++17（原生 Win32 API，无任何第三方 UI 框架）
- 转码引擎：FFmpeg（进程调用方式，主程序内存占用仅数 MB）
- 界面：极简风格，一眼看懂 —— 选文件 → 选格式 → 点转换 → 出音频

## 目录结构

```
高岛的钢琴课\
├── src\             源码
│   ├── main.cpp         界面入口（Win32）
│   ├── converter.cpp    核心：调用 ffmpeg 提取/转码
│   ├── converter.h
│   └── formats.h        音频格式定义
├── bin\
│   └── ffmpeg.exe       FFmpeg 静态版（单文件，随项目附带）
├── output\          输出音频目录（自动生成）
├── build\           编译中间产物
├── build.bat        一键编译
└── README.md
```

## 支持的输出格式

| 格式 | 特点 |
|---|---|
| MP3  | 有损，最通用 |
| WAV  | 无损，未压缩（体积大） |
| FLAC | 无损，压缩 |
| M4A  | 有损，苹果系（AAC） |
| OGG  | 有损，开源 |

## 使用方法

1. 双击 `高岛的钢琴课.exe`
2. 点「浏览…」选择视频文件
3. 点选输出格式（默认 MP3）
4. 点「开始转换」，完成后自动询问是否打开输出文件夹

输出文件默认保存在 `output\` 目录，与源文件同名；若已存在会自动加 `_1`、`_2` 后缀。

## 重新编译

双击 `build.bat`（使用本机 Visual Studio 的 MSVC 编译器）。

## 说明

- 若所选文件不含音轨，会弹出失败提示（例如纯图片或无声视频）。
- 转换期间界面锁定，完成后恢复，状态栏实时显示进度。
